## 1. Назначение

Документ дополняет SRS и уточняет границы, роли и правила поведения, необходимые для UML-моделирования динамических сценариев Pomodoro-таймера.

## 2. Границы системы

**Входит в модель:** нативное окно WinAPI, контроллер таймера, локальные задачи, журнал сессий, аналитика, локальные уведомления Windows и экспорт CSV.

**Не входит:** облачная синхронизация, совместная работа нескольких пользователей, интеграция с внешними таск-трекерами и мобильная версия.

## 3. Актёры

| Актёр | Роль |
|---|---|
| Пользователь | Управляет фокус-сессиями, ведёт локальные задачи и использует личную статистику продуктивности. |
| Windows | Внешняя ОС, показывающая локальное уведомление после завершения фазы. |

## 5. Спецификации вариантов использования

### UC-01. Управлять фокус-сессией

**Объяснение.** Пользователь запускает рабочий интервал, приостанавливает, возобновляет или сбрасывает его.

**Предусловия.** Приложение запущено; параметры длительности фаз загружены.

**Основной поток.** Пользователь нажимает «Старт»; система создаёт текущую сессию и запускает обратный отсчёт. При окончании времени система фиксирует результат, определяет следующую фазу и показывает уведомление.

**Альтернативные потоки.** Пользователь может выбрать «Пауза» и затем «Продолжить». При «Сбросить» отсчёт прекращается, а запущенная рабочая сессия фиксируется как прерванная.

**Постусловия.** Экран отражает актуальную фазу и время; завершённая или прерванная рабочая сессия присутствует в журнале.

### UC-02. Выбрать активную задачу

**Объяснение.** Пользователь связывает текущую или следующую фокус-сессию с задачей из локального списка.

**Предусловия.** В списке существует хотя бы одна незавершённая задача.

**Основной поток.** Пользователь выбирает задачу; система сохраняет её идентификатор как активный и выводит название в главном окне.

**Альтернативный поток.** Пользователь снимает выбор; сессия запускается без связи с задачей.

**Постусловия.** Следующая запись журнала содержит выбранную задачу либо пустую связь.

### UC-03. Управлять задачами

**Объяснение.** Пользователь добавляет, изменяет, завершает или удаляет локальные задачи.

**Предусловия.** Приложение запущено.

**Основной поток.** Пользователь вводит данные задачи или изменяет существующую запись; система проверяет название и сохраняет список.

**Альтернативный поток.** При попытке сохранить пустое название система сообщает об ошибке и не изменяет список.

**Постусловия.** Список задач и доступный выбор активной задачи обновлены.

### UC-04. Просмотреть журнал сессий

**Объяснение.** Пользователь изучает историю завершённых и прерванных фокус-сессий.

**Предусловия.** Журнал доступен локально.

**Основной поток.** Пользователь открывает журнал и при необходимости задаёт период, статус или задачу; система выводит подходящие записи.

**Постусловия.** Данные журнала отображены без изменения исходных записей.

### UC-05. Анализировать продуктивность

**Объяснение.** Пользователь получает сводные показатели по дням, неделям и задачам.

**Предусловия.** В журнале есть хотя бы одна запись или допустим пустой результат.

**Основной поток.** Пользователь открывает аналитику и выбирает период; система агрегирует журнал и показывает карточки итогов, график и таблицу задач.

**Постусловия.** Пользователь видит рассчитанные показатели; данные журнала не изменяются.

### UC-06. Настроить цикл Pomodoro

**Объяснение.** Пользователь устанавливает длительности фаз и число рабочих сессий до длинного перерыва.

**Предусловия.** Нет активного отсчёта.

**Основной поток.** Пользователь вводит допустимые значения; система проверяет диапазоны и сохраняет настройки.

**Альтернативный поток.** При недопустимом значении система показывает ошибку и сохраняет прежние параметры.

**Постусловия.** Новые настройки применяются к следующей сессии.

### UC-07. Экспортировать статистику в CSV

**Объяснение.** Пользователь сохраняет сводный список сессий для работы во внешней таблице.

**Предусловия.** Сформирована выборка журнала или аналитики; пользователь выбрал путь сохранения.

**Основной поток.** Пользователь выбирает «Экспорт CSV»; система формирует UTF-8 CSV с заголовками и сообщает об успешном сохранении.

**Альтернативный поток.** При невозможности записи система сообщает причину; существующие данные не изменяются.

**Постусловия.** При успехе по указанному пути создан CSV-файл.

## 6. Правила поведения

| Тема | Правило |
|---|---|
| Управление таймером | Одновременно может выполняться только одна фокус-сессия. |
| Сброс | Сброс активной рабочей фазы фиксирует её как прерванную; сброс до запуска журнала не создаёт. |
| Смена фаз | После завершённой рабочей фазы назначается короткий перерыв, а после заданного числа рабочих фаз — длинный. |
| Журнал | Сессия записывается до пересчёта аналитики и экспорта. |
| Уведомления | Завершение фазы сопровождается локальным уведомлением Windows. |
| Экспорт | CSV содержит отфильтрованные записи в UTF-8 с заголовками столбцов. |

## 7. Нефункциональные ограничения

| Идентификатор | Категория | Спецификация |
|---|---|---|
| AS-01 | Платформа | Windows 10/11, нативный настольный клиент. |
| AS-02 | Технологии | C++20 и WinAPI; браузер и сеть не требуются. |
| AS-03 | Производительность | Открытие главного окна и переключение экранов — не более 2 секунд при журнале до 10 000 записей. |
| AS-04 | Точность | Отображение оставшегося времени обновляется не реже одного раза в секунду. |
| AS-05 | Хранение | Задачи, настройки и журнал сохраняются локально в JSON; передача данных наружу отсутствует. |
| AS-06 | Экспорт | CSV создаётся в UTF-8 с полями: дата, задача, фаза, длительность, статус. |
