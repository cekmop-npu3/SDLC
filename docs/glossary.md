## Назначение

Глоссарий задаёт единые определения терминов предметной области и проектных артефактов для SRS, SDD, UML-диаграмм и дополнительных спецификаций.

## Глоссарий

| № | Термин | Англ. | Определение |
|---|---|---|---|
| 1 | Актёр | Actor | Роль внешнего пользователя или внешней системы по отношению к Pomodoro-таймеру. |
| 2 | Прецедент | Use Case | Типовой сценарий взаимодействия актёра с системой. |
| 3 | Поток событий | Flow of Events | Описание обработки: объяснение, предусловия, основной и альтернативные потоки, постусловия. |
| 4 | Pomodoro | Pomodoro | Метод работы короткими сфокусированными интервалами с перерывами. |
| 5 | Фокус-сессия | Focus session | Экземпляр рабочего интервала, запускаемый для выполнения активной задачи. |
| 6 | Рабочая фаза | Work phase | Фаза обратного отсчёта, в которой пользователь выполняет задачу. |
| 7 | Короткий перерыв | Short break | Перерыв между обычными фокус-сессиями. |
| 8 | Длинный перерыв | Long break | Перерыв после заданного количества завершённых фокус-сессий. |
| 9 | Активная задача | Active task | Задача, связанная с текущей или следующей фокус-сессией. |
| 10 | Журнал сессий | Session journal | Локальная история завершённых, прерванных и сброшенных сессий. |
| 11 | Аналитика | Analytics | Агрегированная статистика журнала по дням, неделям и задачам. |
| 12 | Уведомление | Notification | Локальное системное сообщение Windows о переходе фазы. |
| 13 | CSV-экспорт | CSV export | Выгрузка статистики в файл, открываемый табличными редакторами. |
| 14 | SRS | Software Requirements Specification | Спецификация требований к ПО. |
| 15 | SDD | Software Design Description | Описание проектирования ПО. |
| 16 | ADR | Architectural Decision Record | Запись архитектурного решения с обоснованием. |
| 17 | UML | Unified Modeling Language | Язык моделирования структуры и поведения системы. |
| 18 | Include | Include | Связь включения обязательного фрагмента поведения в прецедент. |
